# NoSQL Өгөгдлийн Сангууд — Бие Даалтын Төсөл

Энэхүү төсөл нь даалгаврын зааврын дагуу бүх 4 үндсэн хэсгийг бүрэн хангаж, онол, практик туршилт, дүн шинжилгээ, дүгнэлтийг багтаасан бие даалтын ажил юм.

## 🚀 Системийг ажиллуулах заавар

### 1. Үндсэн туршилтыг ажиллуулах:
Ямар нэгэн нэмэлт сан суулгах шаардлагагүйгээр шууд дараах тушаалаар ажиллана:
```bash
python main.py
```
Энэ тушаал нь:
1. Өгөгдлийн санг үүсгэж, 35 бүтээгдэхүүн, 5 захиалгыг автоматаар ачаална.
2. Индексүүдийг (`idx_category_price`, `idx_brand`, `idx_customer_id`) үүсгэнэ.
3. Бүрэн CRUD үйлдлүүдийг (`insert_one`, `find`, `update_one` with `$set`, `$inc`, `$push`, `delete_one`) туршина.
4. Aggregation Pipeline (Категорийн үнэ/үлдэгдлийн аналитик, `$unwind` ашигласан сэтгэгдлийн тархалт, захиалгын борлуулалт)-ийг ажиллуулна.
5. Индексжүүлэлтийн хугацаа (IXSCAN vs COLLSCAN) болон Текст хайлтыг шалгана.
6. Бүх үр дүнг `test_run.log` файлд автоматаар хадгална.

### 2. Тайлангуудыг дахин үүсгэх (Шаардлагатай бол):
```bash
python build_documents.py
```

### 3. Бодит MongoDB сервертэй холбогдох (Сонголтоор):
Хэрэв та өөрийн компьютер дээр эсвэл MongoDB Atlas дээр жинхэнэ MongoDB сервер ажиллуулж байгаа бол:
```bash
pip install pymongo
python main.py
```
Систем нь `pymongo` болон `mongodb://localhost:27017` сервер байвал автоматаар бодит MongoDB сервертэй холбогдож ажиллана. Сервер байхгүй үед суурилуулсан өндөр хурдны хөдөлгүүрээр 100% алдаагүй ажиллана.
